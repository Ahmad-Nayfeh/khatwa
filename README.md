# khatwa (خطوة)

**English summary:** khatwa is a free, open-source Android app (MIT) that counts your daily steps from the phone's built-in step sensor, shows light statistics and a daily quote, and can lock the phone (except apps you allow) until you walk a set number of steps. A small Windows companion locks your laptop at login until you enter the daily code the app reveals once you hit your goal. Everything works offline; nothing leaves the phone. Work in progress: this README will be completed when the app is finished.
